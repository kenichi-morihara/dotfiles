# シェルの初回遅延を測る

新しいターミナルでzenoの機能（Ctrl+Gなど）を初めて使うと、
`zeno-init` を計測します。初期化が100ms以上なら、ショートカットから戻ったあとstderrに自動通知します。
Ctrl+Gは選択・キャンセル後に表示するので、計測コマンドを手入力する必要はありません。
100msは運用上の初期値で、感じ方に合わせて変更してください。
fzfで選んでいる時間は計測に含めません。

```text
[latency] zeno-init: 342ms (threshold 100ms)
```

記録はシェルのメモリ内だけに保持します。ファイルには保存しません。

```zsh
dotfiles-latency          # このシェルの計測結果
dotfiles-latency probe    # ghqのrepo列挙だけを追加計測
```

閾値を変える場合は `~/.zshrc.local` に設定します。

```zsh
export DOTFILES_LATENCY_THRESHOLD_MS=50
```

この設定は既存の遅延初期化を維持します。zeno自体を起動時に実行したり、
キャッシュの削除・生成やバックグラウンドプロセスの起動を追加したりはしません。
すでにzenoを初期化したシェルではなく、新しいターミナルで初回を確認してください。

次の切り分けは、初期化時間が大きければDenoキャッシュ確認とソケット準備の個別計測、
repo列挙が大きければghqルートの走査です。表示後の操作感は別に評価します。
通知はショートカットから戻ったあとです。固まっている最中の通知には別途監視が必要です。
