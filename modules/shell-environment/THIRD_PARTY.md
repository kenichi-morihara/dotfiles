# 依存元と配布範囲

home/dot_config/ranger/commands_full.py は ranger 由来で、原ファイルのライセンス注記が適用されます。
ranger の GPL version 3 本文を licenses/ranger-GPL-3.0.txt に同梱しています。MIT は独自の設定接続コードに適用し、ranger 由来ファイルの条件を変更しません。

zinit と各プラグイン、starship、zeno、Deno、Lua、fzf、ghq は外部依存です。プラグインの取得先は scripts/common/zinit.zsh に記載しています。
